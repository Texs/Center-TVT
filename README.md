# Center-TVT
Water water preparation and filtering solutions for wastewater and drinking water

Дальнейшее развитие приложения

Добавление базы данных фильтров с характеристиками

Интеграция с API производителей фильтров

Визуализация результатов анализа

Расчет  систем очистки

Возможность сохранения результатов анализа

Это приложение поможет пользователям быстро определить проблемы с качеством воды и подобрать оптимальные современные методы очистки.


Основные изменения:
Добавлен показатель натрия в таблицу нормативов:

СанПиН 2.1.4.1175-02: 200 мг/л

ВОЗ: 200 мг/л

Добавлены методы очистки натрия:

Обратный осмос (наиболее эффективный бытовой метод, удаляет 85-95% натрия)

Электродиализ (используется в промышленных установках)

Дистилляция (удаляет все соли, но энергозатратный)

Ионообмен с селективными смолами (специализированные смолы для натрия)

Улучшен интерфейс ввода:

Теперь можно пропускать параметры, нажимая Enter

Добавлена обработка некорректного ввода

Дополнительная информация:

При обнаружении повышенного содержания натрия выводится развернутая информация о методах очистки

Обновлен вывод нормативов:

Теперь таблица включает показатель натрия

Дополнительная информация по очистке натрия:
1. Обратный осмос - удаляет 85-95% натрия, наиболее эффективный бытовой метод
2. Электродиализ - используется в промышленных установках
3. Дистилляция - удаляет все соли, но требует много энергии
4. Ионообмен с селективными смолами - специализированные смолы для натрия
Это обновление делает приложение более полным и полезным для пользователей, обеспокоенных содержанием натрия в воде, что особенно актуально для людей на низкосолевых диетах.
